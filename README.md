# ✈️ 机票价格全网监控系统 (GitHub Pages 云端免开机版)

无需本地电脑开机，基于 **GitHub Public 仓库 + GitHub Pages + GitHub Actions** 全天候 24 小时云端托管，支持 **电脑浏览器** 与 **iOS 手机（Safari / 主屏幕独立 PWA 应用）** 随时随地查看。

本项目包含两个版本（页面支持 1 键互相跳转）：
- 🇮🇹 **中意专版 (4/10 上海 ⇄ 4/24 米兰/罗马 开口往返)**：[访问根目录 `/`](https://frankwyh.github.io/flight-monitor/)
- 🌍 **全球/全国通用版 (自选任意起终点 + 模糊时间段 + 分级神券)**：[访问通用版 `/universal/`](https://frankwyh.github.io/flight-monitor/universal/)

## 🌍 版本二：全球/全国通用版 (`/universal/`)
- **起终点自由选**：内置 55+ 国内各大干线与全球主流枢纽机场，支持自定义三字码输入，支持主目的地 A + 开口目的地 B。
- **3 种灵活日期模式**：
  1. **🔀 模糊时间段**：设定「最早出发日 ~ 最晚出发日 + 停留天数范围（如玩 5~7 天）」，系统自动计算矩阵内每天往返的供需因子与价格，列出前 16 个性价比最高的「出行日期黄金组合」。
  2. **📅 精确日期**：指定去程与返程确切日期，自动横向对比前后 ±3 天的错峰差价。
  3. **🗓️ 整月/节假日低价日历**：一键生成指定月份 30/31 天的往返低价探索日历，并提供元旦、春节、清明、五一、暑期、国庆一键快选。
- **快捷任务监控夹**：支持将常用航线保存到快捷栏，一键直达。

## 🎟️ 优惠券分级体系说明（解答：优惠券是人人都能领取的吗？）
为了避免“把用户没有的会员大额券算进票价导致虚假低价”，系统严格将平台优惠券划分为三级透明体系：
1. **🟢 第一级：公开普惠券（人人免费可领 · 系统默认开启）**
   - 只要下载飞猪/携程/去哪儿 App 或在航司官网注册免费账号，即可直接点击领取的普惠券（如飞猪出境补贴满3000减100、携程国际多程满3500减120、航司新会员注册券等）。
   - **特点**：无门槛、无付费会员限制，所有人都可以按照页面标注的路径领到并抵扣。
2. **🟡 第二级：银行卡/限时整点抢（按需开启）**
   - 银联云闪付、指定银行信用卡跨境立减（满3000减50~60）或每周四固定时间限时抢券。
3. **🟣 第三级：高门槛/付费会员专属（系统默认关闭！）**
   - 包含 **淘宝 88VIP** 专享券（满4000减180）、**携程钻石/黑钻会员** 两舱券（满10000减400）等。
   - **特点**：普通用户无法直接获取。默认关闭，用户在页面上手动开启后才会计入。

## 🔄 刷新机制
1. **GitHub Actions 自动巡检（每天 2 次）**：
   - 每天北京时间 **09:00** 与 **21:00** (`cron: '0 1,13 * * *'`) 自动运行脚本拉取最新运价并推送到 GitHub Pages。
2. **页面右上角手动刷新（随时点按）**：
   - 点击 **「🔄 手动刷新」** 按钮，浏览器端即时重算最新全网价格、汇率与优惠券组合。

## 📱 iOS 手机查看与独立 PWA 体验
1. 使用 iPhone Safari 打开 `https://frankwyh.github.io/flight-monitor/`
2. 点击 Safari 底部 **「分享」** 按钮（方框带向上箭头）
3. 选择 **「添加到主屏幕」**
4. 手机桌面即可生成专属飞机图标 App，支持离线缓存与全屏原生沉浸式浏览！
